# Weekly cross-project learning and governed publication

Owner-authorized cadence: once weekly. Collect project lesson/decision/postmortem
changes, verify actual sources and integrate narrow reusable methods into the
corresponding authored Skill or governance rule. Use the registered local
Agent-rules-skills workflow and its validated scan/stage/prepare/publish tool.
The owner-designated public repository is mingpeng2004/Agent-rules-skills.

Skills are not promoted from anecdotes: require an applicable counterexample,
actual verification, source/version binding and a reviewed change. Reuse existing
project authority, client variants and skill catalog; no product behavior change
is implied by a maintenance task. No metrics, root cause or elapsed-time approval
may be invented. Unchanged sources need no artificial edit or empty commit.

Public output includes portable governance, reviewed Skill variants, original
notices/licenses, exhaustive discovery status and sanitized test/hash evidence.
Original private project paths, .agentos state, credentials, raw traces, dumps,
business source and measurements remain local. Vendor internal skills with no
established redistribution right remain reference-only in the catalog.

Native weekly scheduling is maintained by the calling client; installation of
this file adds no daemon. Verify saved schedule and actual publication readback.
Do not claim a future scheduled firing or unattended success before observing it.
Scan failures retain exact local reasons and appear as coverage gaps publicly.
