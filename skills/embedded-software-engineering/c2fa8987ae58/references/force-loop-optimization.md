# 力环优化的证据驱动方法

用于力/压力闭环精度、扰动恢复、双向差异、参数不生效、采样/输出链性能及DOE。来自STM32多电机工程的参数链分析、真实轨迹、生产C行为复现和通信修复经验；这些是可复用方法，不是所有设备可直接套用的增益、死区或通信默认值。

## 1. 先确认证据和控制权

核对真实run ID、原始ADC/标定后的力、目标、方向/阶段、采样序号、时间、版本、配置及完整结束状态。pytest或probe可能写入最近运行指针，先追溯来源，测试写入隔离在创建/写入边界解决。测试后才修改的config不是运行时参数快照；截图/颜色/最新版文件名都不独立证明设备故障。

遵守项目执行器不变量。来源工程规定力补偿只经V5M，Z1M只定位/接近；其他工程必须读取其自己的职责/安全定义，不能把这个轴名推广为通用架构。不得用位置轴参与额外补偿、放宽限位/过载/失联保护来掩盖力环缺陷。

## 2. 工厂成功而生产失败时比较真实调用链

对齐配置版本、目标/测量单位、tare/校准语义、ADC窗口、设备使能/零输出确认、启环、运动交接、停止/释放及异常恢复。找到第一个不同的状态或动作，再复现和修复。启动/安全序列和稳态控制问题分开，不能直接归咎PID或硬件。

尤其检查两端多个入口是否调用同一抽象、参数和状态机。修复所有权/初始化边界，并覆盖工厂/生产/重连/取消回归；仅在失败入口再补几次写参可能继续保留隐藏覆写。

## 3. 参数链与验收口径分离

建立配置/工厂设置 → profile → 编排 → 单位转换/编码 → 设备校验 → 实际状态/寄存器 → 本次请求的ACK/读回 → 实际行为证据。逐状态审计启动、稳力、运动、重连、降级、故障恢复及停止/再启动的覆盖点。

控制死区、控制增益、产品验收带和安全保护是不同量，不互相替代。来源工程曾由等级/百分比/默认值扩大死区，UI设置未保证执行值；启动安全输出重置又可复写配置增益。通用修复是单一参数权威、配置与瞬态状态分离、应用代次/最终值记录、正常/异常/边界红绿测试。该历史缺陷不代表当前版本仍存在。

收到ACK只说明契约规定的确认层级；不能假定参数已生效。旧兼容参数可以保留解析但不得绕回当前控制权威。精度失败不能通过降级、扩大验收带或改变统计口径“修好”。

## 4. 建立端到端速率和延迟模型

分别量测ADC新样本率、控制计算频率、数据上传、Host绘图/滤波、请求调度、线上完成事务率和已确认执行器更新率。高频ISR不代表同频新测量/出力，波特率或Host RTT不等于总线/硬件极限。名义节流间隔不是实际start-to-start间隔。

源工程用生产C在受控ARM仿真中复现了暖机/安全应答归属、RX竞争、释放顺序和冗余位置写。通用方法是单一在途事务拥有者、先确认再推进安全序列、未变方向省去经确认的冗余写、忙时禁止同步路径flush窃取异步响应。离线一笔代替两笔仅证明逻辑事务数，不宣称真实吞吐翻倍。

通信诊断必须核对命令/地址/寄存器/长度/错误语义，拒绝NACK/畸形/迟到/错请求响应。CRC与短帧也可能来自软件竞态或截帧，不能直接判线缆噪声。ISR拥有的时间戳与now应形成一致快照，测试无符号回绕/下溢；失败长度/计数及时保留，避免被下次成功覆盖。

来源修复采用先读ISR最后事件时间、再读now，避免取样顺序产生假大时间差；这是有序读取，不是完整原子快照证明。仍需验证字节到达穿插、帧尾判定和计数回绕，不能把两个独立读包装成通用竞态免疫。

Host介导与板端直接基准分开，计数同boot做有符号规则明确的回绕安全差分；错误计数可能重叠，不重复累计。保持采样负载、节流、日志开销和工况匹配，先修通信/观测链再做力环DOE；读地址/写零也属于需现场前置的动作，本参考不授权执行。

## 5. 量化、可达性和测量不确定性

区分内部连续u、请求编码、实际已确认寄存器值及实际作用力。观察到u平台不等于执行器精度下限；源码舍入/缩放只能证明实现映射。传感器噪声、标定、tare、滤波延迟、采样丢失、执行器死区/饱和和力学耦合分别调查。

成功写应答后的命令缓存不等于独立寄存器读回，更不是实测电流、杆位或力。u×1000遥测可能尚未包含输出量化、限幅、热降额和通信落后；内部轨饱和不代表所有执行端限幅已被覆盖。由u与前馈推导的PI合成量包含P和I，不能叫纯积分，钳位时只支持对应边界而非精确分解。多字段遥测还需说明是否同一时刻快照。

在相同负载/位置/供电/测量条件下验证相邻实际输出档的稳态力和动态响应，判断目标是否可达。没有厂商单位/范围依据不改寄存器比例，不从旧模型增益推算精度承诺。不先换硬件、加固定方向偏置或提高输出限制；返程若在不同位置交替高低，一个偏置可能改善一段并损害另一段。

## 6. 全过程、双向、分工况验收

保存原始FWD/BWD明确标签，按时间方向分析，不凭曲线左右位置或全程最大位置猜分段。完整样本检查最大绝对误差、峰峰值、超限次数/最长持续、恢复/过冲、输出切换及丢样；每个方向/模式/重复单独通过。

源工程历史分析中返程均值接近目标却存在长时间正负平台，证明均值会掩盖失败。全程误差带与峰峰值门槛分别判断：PP足够小不保证均值在目标，均值正确不保证任何样本达标。缺标签、NaN/Inf、缺方向、提前结束和不完整重复拒绝排名；不能事后去前段、平滑显示或改成覆盖率来替代用户全程要求。

诊断统计可以报告覆盖率/分位数，但不是未经批准的新验收。扰动恢复预算来自实际工况与测量，不承诺未经测量的恢复毫秒数或7x24稳定性。

## 7. DOE次序与晋升

先确认参数有效和测量/通信链可信，再固定目标、机械工况、ADC/滤波、节流/实际更新、前馈及自适应倍率。死区变更可能同时改变自适应增益，所谓单变量需以启环后的实际快照证明。

固定倍率上限不等于倍率恒定；需要核对调度函数，按契约关闭/明确固定调度，或把耦合作为试验因素。不能仅因ID45前后相同就声称已隔离增益变化。

根据系统辨识和约束选择试验因素/范围；比例响应、积分残差、前馈、滤波等按证据逐项区分，不规定适用所有控制律的固定调参次序。每配方有固定项、重复、停止/恢复、硬门槛和晋升标准；只有全部完整重复和方向通过才能进入候选排名。离线仿真/重放仅筛候选，真实验收之前不改生产默认，不把来源工程的135g、200mg或500mg照搬到别台设备。

## 8. 回归与实机边界

逻辑/协议/参数权威用离线测试，时序/调度可用实际生产代码的有界仿真，必要时注入旧阻塞、覆盖/单位、释放顺序等变异验证测试能失败。未出现真实执行证据时不能宣称力环修复或实机精度通过。

父工具exit0或“全部通过”横幅必须核对子结果；SKIP不是执行链成功，裸payload未按协议封帧的诊断不能证明已出力。运行版本、写入校验、初始化、闭环、双向精度、长期/用户验收分别报告。初始化/探针可能运动，核对工作物/负载、现场、身份与明确授权；失败先保存，不自动重新烧录、唤醒或重放控制命令。

## 9. 每次优化的最小交接

只需在现有任务/契约/验收中保留：目标与执行器不变量、参数来源/实际生效快照、采样/计算/请求/完成速率边界、原始run/方向/完整性、候选根因及反证、配方固定项/停止条件、完整双向指标、版本/产物/证据和下一动作。历史细节按ID检索，不复制整篇事故过程到每轮上下文。

来源索引仅供定向调查：工程的DEC-301/304（工厂交接）、DEC-391（测试trace隔离）、DEC-408（原始双向轨迹/参数链）、DEC-409/410（单一死区与验收分离/DOE软件门禁）、DEC-411（实际C行为和应答归属/时间戳）及工程经验L28/L33/L35/L36/L38。共享包只含方法，不携带原始机台记录、个人路径或设备身份。复用前读当前项目源码/契约，历史分析已被后续实现替代的部分不作为当前缺陷。
