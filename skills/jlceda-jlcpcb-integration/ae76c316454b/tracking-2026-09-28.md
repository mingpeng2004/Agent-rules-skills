## c) 建议改动点（不改文件，仅汇报）

均为**可选增强**，非必须：

1. **API 命名规范**：现文件用大写模块名（`SCH_PrimitiveComponent`、`PCB_ManufactureData`、`SYS_FileManager`）。
   官方实际为**小写下划线前缀**调用（`eda.sch_PrimitiveComponent`、`eda.dmt_Project`、`eda.lib_Device`、`eda.sys_Message`），接口/枚举才用 `ISCH_`/`IPCB_`/`EPCB_`。建议标注两套写法，避免调用方混淆。
2. **新增能力条目**（Phase A/C 可补）：
   - `sch_Netlist.setNetlist` — 网表导入生成原理图（多格式）。
   - `PCB_Document.autoRouting`（**@beta**）— 原生自动布线；建议在 Phase C 注明"当前为 beta，勿生产硬依赖"。
   - 原理图侧 `sch_auto_routing` / `sch_auto_layout`（来自社区工具，非官方 API）。
3. **官方连接路径更新**：补充"官方栈需 EasyEDA Pro **V3.2+**，并用 `run-api-gateway.eext` 扩展（https://jlc-ext.com/item/oshwhub/run-api-gateway ）连接 Bridge Server"。
4. **纠正"EasyEDA Pro AI Schematic Beta"措辞**：现文件 Phase A 写"如果 EasyEDA Pro AI Schematic Beta 可用，优先用 LLM 生成一稿"。检索显示**没有官方第一方 AI 助手**，"AI 原理图"能力主要来自社区扩展（EasyEDA Copilot / jlcmcp / AI 分析助手等）。建议改为"由社区扩展/官方 API 组合实现"，避免暗示存在官方 AI 开关。
5. **制造端可选补充**：可加一行"嘉立创云 ERP 开放平台 API（open.jlc.com，2026-04）提供一键返单"作为备选下单路径；并注明 Partner API 合作方合规条款（2026-03 更新）。
6. **API 规模标注**：可注明官方 API 参考约 **120 classes / ~700 methods**（对应 `easyeda-api-skill` v1.1.36），供评估覆盖面。
