# 上位机与配套软件专业路径

适用于桌面 UI、设备工具、后台逻辑、协议通信、数据记录和打包。语言/框架、事件循环、部署形态从实际工程发现；不强制统一 Python 或某 UI 框架。

## 连接与控制所有权

串口、USB、网络或调试器句柄有唯一拥有者和明确生命周期：未连接、连接中、握手/兼容核对、就绪、工作、断链、恢复、关闭。将打开端口、身份核对、初始化和执行器动作分开，打开连接也可能触发板卡复位，应核对设备行为。

处理拔插/超时/进程退出/端口争用，关闭线程、任务、定时器和文件。重连先核对设备身份/版本/状态，不重放历史运动或非幂等命令。取消操作区分本地停止等待和设备真正停止，两者需要各自证据。

## 协议与双端兼容

明确帧边界、长度上限、端序、单位/缩放、校验、序号、错误和版本/能力协商。覆盖分包/粘包、噪声、无效长度、重复/乱序、迟到回复和断链。解析器在未验证长度前不分配无界缓冲。

区分 transport ACK、业务完成和参数生效。读回关联本次请求/会话及设备状态；无读回能力时说明可确认范围与其他验证方案，不编造设备支持。

Host/FW 变更分别验证并给出兼容矩阵：旧/新组合哪些允许、哪些拒绝或受限。确定升级顺序、部署单独失败时的处理和回退。能力不足不能静默降级到违背精度/安全约束的路径。

## 异步与界面

设备 IO/长计算不阻塞 UI/event loop。跨线程 UI 更新遵循框架规则。任务有超时、取消、错误传播与资源清理；关闭窗口后回调/信号不能访问失效对象。

消息/采样队列有界，写盘/绘图慢时明确背压、降采样或丢弃计数。显示平滑不能替代原始数据记录；UI 当前值不能视作整个测试过程的统计结果。防止重复点击产生并行启动，业务状态与设备实际状态分开显示。

## 配置与实际生效

列出配置来源、默认/用户/会话优先级、UI 校验、转换、请求编码、设备校验/覆盖和读回。重点检查启动、重连、模式/方向切换、失败恢复时的默认复写。

持久配置有 schema/迁移/原子写入/损坏恢复；日志记录最终生效值及来源，不输出凭据。改一个设置控件不代表所有运行入口都采用了它。

## 数据与测试隔离

真实记录绑定 run ID、设备、版本、配置、单位、时间基准、采样序号/丢失及状态。明确时钟同步/漂移，派生指标保留输入和计算方法。

测试使用隔离目录和临时默认实例/依赖注入，不能写真实 `LATEST`、默认日志单例或生产记录。只靠测试结束后恢复指针不足以防并行污染；应在写入边界隔离。历史数据和新版本结果不能混用。

## 打包与维护

绑定有效运行版本、源码、依赖锁定、构建配置、产物哈希。源码中的版本字符串不一定是有效赋值，验证实际导入/启动版本；部署 EXE/包可能滞后，核对实际启动路径及模块搜索路径。

采用项目批准的可审计打包形式，完整记录依赖/许可证与来源。不要隐藏脚本或 payload、关闭安全扫描来获得“可运行”；项目禁止的打包形式不得使用。签名/发布、外部依赖或更新网络需授权。

验证正常/异常/边界、失联/重连、重复启动/关闭、配置/数据损坏和慢消费者。性能结论覆盖 UI 延迟、内存/句柄/线程趋势及日志容量的实际工况；未执行长跑不宣称 7×24 验收。
