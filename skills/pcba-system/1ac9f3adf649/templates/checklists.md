# PCBA 系统级检查清单（八节通用版）

> 每节对应一个阶段门禁。标注【否决】的条目失败即整门 FAIL，不得豁免。
> 每项执行后必须有证据（文件/命令输出/截图）并在 decisions 日志留痕。

## C0 设计意图评估（P0）
- [ ] 需求逐条摘录无遗漏（含转写来源二次确认）
- [ ] 硬约束无量词歧义（尺寸/层数/精度/不可回退项）
- [ ] 每条 G 指标四要素齐全：量化目标/达成条件/验证方法/证据路径
- [ ] 每条 EI 意图映射到至少一个阶段
- [ ] 最高风险项识别并标注验证优先级 + fallback 预登记
- [ ] 可行性预算完成（理论估算引用数据手册表号）

## C1 选型锁定（P1）
- [ ] BOM 每行：精确 MPN + 料号 + 封装 + 用量
- [ ] 关键器件手册存档；封装图纸与符号引脚语义一致
- [ ] 订购后缀消歧（容值/精度/温漂等级写明）
- [ ] 设计关键元件单独登记；生命周期/库存检查留日期
- [ ] 替代方案分类：drop-in / 有界变更 / 需重设计 / 拒绝
- [ ] 料号来自实际供应商页面核验，非凭记忆

## C2 原理图冻结（P2）
- [ ] ERC 0 error / 0 warning
- [ ] 【否决】引脚映射取自实际采购封装列，逐行对照手册引脚表留证据页码
- [ ] 电源树可画出（源→转换→负载→去耦），电压域表一致
- [ ] 每个电源引脚近端去耦（容值按手册，VCAP 不遗漏）
- [ ] 复位/启动/编程电路符合手册
- [ ] 悬空输入全部清点并标注 NC（有依据）
- [ ] 绝对最大值校核（含未供电输入耐受）
- [ ] intent.connections 逐条对账
- [ ] 人可审阅（分区/命名/无重叠）
- [ ] 【评审团】R1 原理图审查员 + R2 电源完整性 + R8 可靠性降额会审完成，
      纪要 reviews/P2_minutes.md 落盘；发现五要素齐全；无未处置 BLOCKER

## C3 布局冻结（P3）
- [ ] 架构流向符合信号流（接口→保护→转换→处理→输出）
- [ ] 去耦紧贴供电引脚（<500mil）；反馈回路紧致
- [ ] 精密前端远离热源/数字开关；关键器件按风险项摆位
- [ ] 时钟靠近负载，下方无穿越
- [ ] 层策略确认，关键信号回流路径完整
- [ ] 元件间距 ≥0.5mm（焊盘对焊盘）；插装件 courtyard 无冲突
- [ ] 铜/过孔距板边 ≥0.3mm；安装孔/禁布区落实
- [ ] 连接器成熟度四项（映射/料号/几何/空间）
- [ ] 极性标识 + 板名版本丝印齐全
- [ ] 【评审团】R3 信号完整性 + R4 EMC + R7 热设计 + R5 DFM + R6 可测试性会审完成，
      纪要 reviews/P3_minutes.md 落盘（域清单 D-07~D-10/D-12 命中项逐条过）

## C4 布线闭合（P4）
- [ ] 【否决】未连接对象 = 0
- [ ] 【否决】DRC error = 0（间距/交叉/板边/courtyard 全类别）
- [ ] 同网多引脚全部物理连通（抽查所有电源输入对）
- [ ] IPC-2221 载流校核记录最窄线宽
- [ ] 地平面完整无意外开槽，缝合到位
- [ ] 敏感线短且远离干扰源
- [ ] 长度匹配仅在预算要求的网络执行
- [ ] 丝印 warning ≤ 批准基线，超出逐条登记
- [ ] 布线后 ERC 复跑不变
- [ ] 自动工具输出同样过全量 DRC
- [ ] 【评审团】R3 + R4 + R5 会审 + R1 连通性复核，纪要 reviews/P4_minutes.md 落盘，
      无未处置 BLOCKER

## C5 制造发布（P5）
- [ ] 【否决】Gerber 从最终 PCB 重新导出（时间戳 > 最后修改）
- [ ] 层集完整（铜/阻焊/字符/板框/钻孔同批次）
- [ ] 【否决】ORDER_README 层数/板厚/尺寸与 Gerber 实际一致
- [ ] 旧版/缺陷文件隔离 _superseded_<日期>/ 并标注禁止上传
- [ ] 工程/Gerber/文档版本号一致
- [ ] manifest 生成且 verify 通过
- [ ] 工艺规则在目标厂免费工艺内
- [ ] 【评审团】R5 DFM + R6 供应链会审，纪要 reviews/P5_minutes.md 落盘

## C6 组装发布（P6）
- [ ] 【否决】LCSC 料号 100% 覆盖
- [ ] BOM 合并规则正确；CPL 由实际布局生成
- [ ] 【否决】JLC 网站 CPL 预览人工核对极性方向并留截图
- [ ] 代料走独立审批
- [ ] 价格/贴装/支付审批分离
- [ ] BOM/CPL/Gerber 同一 manifest 哈希集

## C7 验证落地（P7）
- [ ] 最高风险 G 指标优先实测
- [ ] 条件达标项按锁定条件测试（配置写明）
- [ ] 报告含原始数据/环境/仪器编号/判定
- [ ] conditional-pass 全部转正或走 fallback 并重跑级联门禁
- [ ] 最终报告：每项指标 实测 vs 目标 + 证据链接
