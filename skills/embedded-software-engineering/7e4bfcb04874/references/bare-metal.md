# 裸机固件专业路径

适用于 MCU 裸机、启动/链接、外设、中断、DMA 和控制时序。MCU/芯片修订、板卡和工具链从工程/手册确认，不把 STM32 特性套到所有平台。

## 发现与输入

确认目标架构/ABI、芯片与板卡修订、时钟/供电/存储、编译链接参数、启动文件、链接脚本、设备头文件/SDK、调试/烧录入口。读芯片参考手册、勘误与板级原理图的适用内容；资料不可用时标未知，不猜寄存器含义。

## 启动与存储

- 核对向量表、复位入口、初始栈、data 拷贝/bss 清零、运行库初始化、异常处理、Bootloader 跳转/向量重定位及保留区。
- 通过 map/section 核对 Flash/RAM、栈堆、DMA 可访问区、对齐、只读/可执行权限（平台支持时）；避免配置/校准/引导区域重叠。链接成功不证明运行内存安全。
- 复位原因需在被清除前按硬件规则保存；异常现场记录必要寄存器/上下文，避免在异常中不受限分配或格式化日志。
- NVM 写入定义版本、完整性、原子提交及掉电恢复；擦除粒度/寿命来自设备资料。不为方便烧录默认整片擦除用户数据。

## 时钟与外设资源

核对时钟树、总线分频、定时器来源、时间基准、引脚复用、电平与外设资源冲突。依据实际时钟计算周期/波特率，并通过适用证据核对；宏定义不是实际时钟测量。

启动顺序考虑输出默认态、上下拉、使能极性和电气状态；安全输出由原理图/项目安全定义确认。GPIO、定时器、DMA 通道、中断和缓冲分配有单一所有者。修改共享定时器不得只测一个消费者。

## 中断与前后台

列出中断来源、优先级/屏蔽关系、触发频率、最长执行/嵌套、共享变量和允许调用。核对架构的优先级编码，不凭数值大小推断高低。

ISR 保持有界，避免阻塞、无界循环、同步输出和不适用的库调用。检查标志清除顺序、读写副作用、丢事件、溢出及重入。`volatile` 不提供原子性、互斥或跨核/DMA 一致性；按架构和编译器选择原子操作、屏障、短临界区或缓冲所有权协议。

主循环/状态机分析最大阻塞、超时来源和回绕。时间差使用目标宽度的安全比较，覆盖计数器回绕、单位换算和乘法溢出。高优先级频繁中断可能饿死前台，不能仅看平均 CPU 使用率。

## DMA 与缓存

确认 DMA 地址可达、长度/对齐/生命周期、完成/错误中断、双缓冲或环形所有权。缓冲在传输完成前不得释放、越界重用或被 CPU 修改。

存在 cache 时核对 cache line 对齐、clean/invalidate 时机、共享 line、内存属性和屏障；无 cache 时仍检查总线/内存可达和并发。不得无证据套用固定 cache 操作序列。传输完成要按外设定义区分“DMA 搬运完成”和“线上的最后字节完成”。

## 控制与安全

控制环采样/计算/输出保持时序可追踪，预算考虑测量延迟、滤波和执行器饱和。参数单位/缩放、限幅、积分饱和、状态切换与复位行为明确。限位、失联、传感器失效及急停按项目定义处理；不能用软件修正冒充电气保护。

调参前验证实际生效值和完整工况，建立稳定基线。离线推导不是实机收敛/安全证据。

## 验证与交付

离线适用检查：编译告警/静态分析、map/section 与预算、协议/整数边界/状态机测试、启动及外设初始化的源码审查。

获得明确授权后，设备验证才覆盖：启动/复位、实际时钟/波形、ISR/循环延迟、DMA 完整性、失联/故障/恢复及项目控制工况。记录目标身份、工具配置、源码/产物哈希、写入范围、校验、启动版本与实际行为。调试器暂停、软件断点和 semihosting 可改变时序，性能结论注明条件。
