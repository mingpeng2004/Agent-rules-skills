# 设计评审团（Design Review Board）机制

> 灵感来源：settchan2003-design/kicad-schematic-review-skill（证据优先评审）、Diode AI 硬件审查器、
> Keitark 工程审查清单、KiCad Design Review 40 检测器、IPC/SI/PI/EMC 行业实践（详见 sources.md）。
>
> 核心思想：**评审不是"再看一遍"，而是多角色、按域清单、证据可溯源的专业判断**。
> 每个角色只对自己的专业域负责；每个发现必须有严重级/置信度/证据来源。

## 一、什么时候触发评审（与阶段门禁绑定）

| 门禁 | 必到角色 | 产出证据 |
|---|---|---|
| P2 原理图冻结 | R1 原理图审查员、R2 电源完整性、R8 可靠性（降额） | `reviews/P2_minutes.md` + 各角色发现清单 |
| P3 布局冻结 | R3 信号完整性、R4 EMC、R7 热设计、R5 DFM | `reviews/P3_minutes.md` |
| P4 布线闭合 | R3、R4、R5 + R1 复核连通性结论 | `reviews/P4_minutes.md` |
| P5 制造发布 | R5 DFM、R6 供应链 | `reviews/P5_minutes.md` |
| 任何域清单命中高风险项 | 追加对应域深审 | 追加发现清单 |

**评审不通过的门禁规则**：存在 BLOCKER 级发现 → 该门 FAIL；WARN 级发现 → 逐条登记"修复或论证接受"，论证需写入 decisions.log。

## 二、角色定义（R1~R8）

### R1 原理图审查员（Schematic Reviewer）
- **触发**：P2 必到；P4 复核。
- **输入**：网表/连接 JSON、数据手册（实际 PDF，非供应商 HTML 包装页）、intent.connections。
- **检查域**（借鉴 settchan 技能的 IC 实例审查法）：
  - 每个 IC 逐实例审查：电源脚/地脚/使能/复位/启动/模式/基准/检测/裸焊盘，逐脚对照手册要求
  - 手册规定的外部元件齐备性：去耦、大电容、自举/电荷泵、检测电阻、上下拉、吸收、TVS/ESD、时钟、反馈网络
  - 连接器/端子/保险丝/检测电阻的额定值 vs 实际电流路径（P/V 估算，效率与启动/堵转裕量）
  - 悬空脚、缺失上拉、错误使能极性、网络短路、电平域不匹配
- **方法纪律**：先抽取事实（extract）→ 手册形成引脚级设计契约（contract）→ 实例对照 → 报告；抽取器与图纸冲突时以原始图纸为准并记录解析局限。
- **输出**：每 IC 一份实例审查卡 + 汇总发现清单。

### R2 电源完整性工程师（PI）
- **触发**：P2 必到（有 DC-DC/LDO/多电源轨时不可缺席）。
- **检查域**：
  - 反馈分压计算（Vout = Vref×(1+Rtop/Rbot)），核对每路电源输出电压
  - 使能链/上电时序（依赖关系、复位释放顺序）
  - 每颗电源芯片的输入/输出电容按手册选型（容值/ESR/耐压），补偿网络
  - 浪涌/静态电流/休眠电流预算
  - 去耦层级：小容值贴近引脚（pad→via→plane 最短回路），中频电容环形散布
- **输出**：电源树核对表 + 每路电源的计算证据。

### R3 信号完整性工程师（SI）
- **触发**：P3/P4 必到（有高速/差分/精密模拟时）。
- **检查域**：
  - 回流路径连续性：高速/敏感信号下方参考平面无跨分割；换层处回流过孔伴随（≤50mil）
  - 3W 规则：高速线中心距 ≥ 3×线宽；差分对对称等长
  - 阻抗：目标阻抗在设计前定义、板材叠层与线宽匹配、阻抗测试Coupon要求
  - 过孔几何：高速路径过孔数量、stub、反焊盘
  - 长度匹配仅在有预算的网络执行，禁止无差别绕线
- **输出**：关键网络 SI 核对表。

### R4 EMC 工程师
- **触发**：P3/P4 必到。
- **检查域**：
  - 完整地平面；禁止高速信号跨平面开槽/分割（跨分割 = 大辐射环 + SI 问题）
  - 地过孔缝合（板边/噪声区周围，间距按最高频率 λ/20，一般 100~200mil）
  - 开关电源/高 di/dt 回路最小化；与安静区正交布线
  - 接口滤波：对外电缆端 TVS/ESD/共模电感；连接器处连续参考
  - 晶振/时钟：靠近负载、下方无穿越、Guard ring
- **输出**：EMC 风险登记表（分区/风险/缓解措施）。

### R5 DFM/工艺工程师
- **触发**：P3/P4/P5 必到。
- **检查域**：目标厂免费工艺边界（线宽/线距/孔径/环宽/板厚/层数）、阻焊桥、丝印可读性、拼板/工艺边、贴片间距 ≥0.5mm、插装件与 SMD courtyard。
- **输出**：DFM 核对表（对照 jlc-fab-rules）。

### R6 可测试性/调试工程师（DFT）
- **触发**：P3 必到（打样前）。
- **检查域**：关键网络测试点可达、编程/调试接口可达（不被屏蔽/遮挡）、上电 bring-up 顺序预案、电流测量断点。
- **输出**：测试点清单 + bring-up 计划草案。

### R7 热设计工程师
- **触发**：存在 >0.5W 耗散器件时 P3 必到。
- **检查域**：θJA 估算 vs 环境温度上限、热过孔阵列、覆铜散热面积、热源与精密元件（基准/传感器）的热间距。
- **输出**：热预算表。

### R8 可靠性工程师（降额审查）
- **触发**：P2 必到。
- **检查域**（降额规则，借鉴 KiCad Design Review 检测器）：
  - 陶瓷电容工作电压 ≤ 额定 50%（电解 ≤ 80%）
  - 电阻功率 ≤ 额定 50%（精密电阻另核温漂指标）
  - IC 各引脚电压/电流在绝对最大值的降额线内
  - 连接器/触点：估计连续电流 > 额定 70% 告警、超过额定判 FAIL
  - 温度等级 vs 应用环境；EOL/NRND 生命周期预警
- **输出**：降额审查表。

## 三、评审方法纪律（所有角色遵守）

1. **证据分层**：抽取事实（工具）/ 数据手册 / 工程判断 / 用户清单，四类证据分开引用，不得混写。
2. **"verified" 禁令**：没有手册摘要或直接手册证据，不得使用"已验证/按手册"措辞；手册缺失时结论标 `manual_review`。
3. **每个发现五要素**：严重级（BLOCKER/WARN/INFO）+ 置信度（高/中/低）+ 证据（位号/引脚/网络/手册页/清单条目）+ 影响 + 可执行建议。
4. **原始抽查**：每个高危发现候选必须在原始图纸处复核抽取连接；抽取与图纸冲突时以图纸为准。
5. **先电流路径后签字**：电源入口→负载→连接器→保险丝→检测电阻的载流路径在签核前必须估算（I=P/V + 效率 + 瞬态）。
6. **冲突取严**：项目本地清单与基准/域清单冲突时执行更严者，除非用户书面豁免。

## 四、输出模板

### 评审纪要（minutes）
```markdown
# <门禁> 评审纪要 — <日期>
| 角色 | 结论 | BLOCKER | WARN | 证据文件 |
|---|---|---|---|---|
| R1 原理图审查员 | PASS/BLOCKED | 0 | 2 | reviews/P2_R1_schematic.md |
...
总体结论：PASS / FAIL（FAIL 理由 + 必修项列表）
登记 WARN 处置：每条 → 修复 / 论证接受（decisions.log 编号）
```

### 单角色发现清单
```markdown
## 发现 F-<角色>-<序号>
- 严重级: BLOCKER | 置信度: 高
- 位置: U3 pin8 [9V] ↔ U3 pin5 [9V]
- 证据: DRC unconnected_items 报告 + 布线抽取 JSON
- 影响: 芯片半边供电悬空，上电失效
- 建议: 并接两引脚（见 fix 记录）
```
