# 域清单库（Domain Checklist Library）

> 专业深度清单，按电路域/工程域组织。评审团各角色按命中域加载对应小节。
> 来源整合：settchan 域清单、Diode 审查分类、KiCad Design Review 检测器、
> Keitark 审查清单、SI/PI/EMC 行业实践（出处见 sources.md）。
> 使用规则：命中即加载；与本项目 checklists.md 冲突时取严。

## D-01 电源入口与保护
- [ ] 输入极性保护（二极管/P-MOS）压降与功耗核算
- [ ] 保险丝额定 vs 最大连续电流（含浪涌 I²t）
- [ ] TVS/ESD：钳位电压 < 后级耐压，布局在入口
- [ ] 浪涌/预充：大电容输入、电池、热插拔场景单独评估 inrush
- [ ] 共模电感/X-Y 电容（市电/长线入口）

## D-02 LDO / DC-DC
- [ ] 反馈分压计算书（Vref 家族核对，~65 族常见值）→ 每路 Vout 复算
- [ ] 输入/输出电容容值/耐压/ESR 符合手册稳定性要求
- [ ] 补偿网络（COT 纹波注入等）按手册
- [ ] BOOT/SW/EN/PGOOD 脚处理；SW 节点面积最小化
- [ ] 电感饱和电流 ≥ 峰值电流 ×1.3；电感温升
- [ ] 效率与热：P_loss 核算 + θJA
- [ ] 电流检测电阻功率降额（I²R ≤ 50% 额定）
- [ ] Bring-up 测试预案：纹波/效率/负载阶跃/短路恢复/SW 应力/测量方法

## D-03 MCU 最小系统
- [ ] 每个电源引脚独立去耦（手册容值）；VCAP 专项
- [ ] 复位：上拉/电容/时序；NRST 走线无干扰
- [ ] 启动模式引脚电平（BOOT0 等）上电瞬间确定
- [ ] 编程/调试口可达（SDI/SWD/JTAG + UART boot）
- [ ] 晶振：负载电容匹配公式（CL=(C1×C2)/(C1+C2)+Cstray）；靠近 MCU；下方禁穿越
- [ ] 未用引脚处置方案（NC 标注 + 内部上下拉）

## D-04 ADC / 精密模拟
- [ ] 基准源：比率式核对（激励与基准同源）；基准去耦按手册
- [ ] 输入 RC 滤波 corner 与数据率匹配；输入泄漏/偏置电流影响
- [ ] 敏感线 Guard/屏蔽；远离开关回路；差分对称
- [ ] PGA 增益与满量程预算（不顶表、不欠幅）
- [ ] 精密电阻对：同批次、紧邻布局、热对称（G4 类温漂指标的物理基础）

## D-05 数字接口
- [ ] I2C：上拉电阻 vs 总线电容 rise-time 计算；地址冲突
- [ ] SPI：CS 数量/拓扑；高速时串阻抑制振铃
- [ ] UART：电平域一致（3V3/5V/RS232）；跨域电平转换
- [ ] CAN：两端 120Ω 终端；共模电感/ESD
- [ ] USB：90Ω 差分、D+/D- 等长、ESD 布局
- [ ] 复位/中断线去抖

## D-06 电流路径与连接器载流
- [ ] 每条电源路径估算：连续/峰值/RMS/启动堵转分开
- [ ] 连接器/触点/导线额定：>70% 告警、超额定 FAIL
- [ ] 并联触点均流；压接/端子规格
- [ ] 采样电阻 Kelvin 连接

## D-07 信号完整性（高速/敏感）
- [ ] 回流路径连续：禁跨平面分割；换层伴随回流过孔（≤50mil）
- [ ] 3W 间距；差分对对称等长；圆弧/45° 转角
- [ ] 阻抗目标前置定义；线宽-叠层-板材闭环；阻抗 Coupon
- [ ] 高速路径过孔最少化；stub 与反焊盘
- [ ] 长度匹配仅预算内网络执行

## D-08 EMC
- [ ] 完整地平面；地过孔缝合（板边/噪声区 100~200mil）
- [ ] 高 di/dt 回路最小化；与安静区正交
- [ ] 对外接口：TVS/共模电感/π 型滤波；连接器处参考连续
- [ ] 时钟区隔离（Guard ring）；晶振不靠近板边/接口
- [ ] 混合信号：单地平面 + 区域布局（模拟/数字分区不分割地）

## D-09 热设计
- [ ] 耗散器件 θJA 估算 vs 环境上限；降额曲线
- [ ] 热过孔阵列（开窗/填充）；散热覆铜面积
- [ ] 热源与精密元件热间距；风道/外壳热路径

## D-10 DFM（JLC 免费工艺基准）
- [ ] 线宽/线距 ≥ 0.127/0.127mm（4层）；孔径 ≥ 0.3mm；环宽 ≥ 0.1mm
- [ ] 板边间距 ≥ 0.3mm；元件间距 ≥ 0.5mm（焊盘对）
- [ ] 阻焊桥 ≥ 0.1mm；丝印字高 ≥ 0.8mm、线宽 ≥ 0.12mm
- [ ] 拼板/工艺边/V-cut；贴片与插混装的工艺顺序

## D-11 降额与可靠性（R8 专用）
- [ ] 陶瓷电容电压 ≤ 50% 额定；电解 ≤ 80%
- [ ] 电阻功率 ≤ 50% 额定；精密电阻核温漂/跟踪
- [ ] IC 引脚 abs max 降额线； latch-up 风险引脚
- [ ] 温度等级 vs 应用；EOL/NRND 预警与替代

## D-12 可测试性/可维护性
- [ ] 关键网络测试点（电源/复位/时钟/模拟输出）
- [ ] 编程口可达；测试点不被器件/屏蔽罩遮挡
- [ ] 电流测量断点（0Ω 电阻/跳线）
- [ ] Bring-up 顺序预案（电源逐级→时钟→复位→外设）
